# GAME FISIKA XII - by suwarni
1. Firebase Console > Authentication > Sign-in method: aktifkan **Anonymous**.
2. Build > Realtime Database > Create database (Spark). Salin URL-nya ke `databaseURL` di `index.html` jika berbeda dari default.
3. Tab Rules: tempel isi `database.rules.json`, lalu Publish.
4. Authentication > Settings > Authorized domains: tambahkan `USERNAME.github.io`.
5. Push semua file ke GitHub, aktifkan GitHub Pages (branch main, root). Buka lewat HTTPS, lalu pilih "Install / Tambahkan ke layar utama".
Kontrol: WASD/Spasi/drag mouse, E = interact/kabel. Mobile: joystick kiri, tombol lompat kanan, geser layar untuk kamera.
